# NBA player tracking and hustle data: free access, endpoints, reliability, and predictive value for rebounds and assists (as of 2026-10-29)

Method note: compiled 2026-10-29 from library source and docs, changelogs, GitHub issues, NBA.com pages, blogs, and papers. No stats.nba.com endpoint was called live from this session (the user's standing rule is to ask before running network commands), so "latest confirmed season" statements rest on changelogs and published pages, not on a live test. Tags used in Q2: [MEASURED] means the source reports numbers from data; [ASSERTED] means a claim without a reported test.

## Q1. Which tracking stats are available per game (box score level) versus only as season or date-range aggregates, and from which season does each start?

### Takeaway
Only two per-game (GameID) tracking endpoints are still served: `boxscoreplayertrackv3` (rebound chances, touches, passes, secondary and free throw assists, speed, distance, contested shooting) and `boxscorehustlev2` (box outs, contested shots, deflections, loose balls, screen assists, charges). Potential assists, assist points created, contested and deferred rebounds, adjusted rebound chance %, drives, time of possession, front court touches and elbow/post/paint touches exist only in dashboard endpoints (`leaguedashptstats`, `leaguehustlestatsplayer`, `playerdashptreb`, `playerdashptpass`) that accept DateFrom/DateTo, so per-game values come from querying one date at a time, a method already implemented in Darryl Blackport's `nba_stats_tracking` package. League-wide tracking starts 2013-14; hustle stats start with the 2016 playoffs; public box outs start in 2017-18 with a methodology change after 2018-19; `synergyplaytypes` is season-level only.

### Cited Findings

#### Provider eras
- League-wide optical tracking of all games began at the start of 2013-14 (STATS SportVU). ([Wikipedia: Player tracking (NBA)](https://en.wikipedia.org/wiki/Player_tracking_(National_Basketball_Association)))
- Announced September 22, 2016: Second Spectrum became "Official Optical Tracking Provider of the NBA" for 2017-18 and Sportradar became "Official Provider of Real-time NBA League Statistics" from 2017-18; the release says fans and media continue to access player-tracking data on NBA.com. ([NBA PR](https://pr.nba.com/nba-announces-multiyear-partnership-sportradar-second-spectrum/))
- From 2023-24, Sony's Hawk-Eye replaced Second Spectrum as lead optical tracking provider; Sportradar works alongside Hawk-Eye to generate tracking data sets, metrics and advanced stats. ([ESPN](https://www.espn.com/nba/story/_/id/35818363/nba-use-hawk-eye-tracking-system-follow-players-ball); [SVG](https://www.sportsvideo.org/2023/03/09/nba-taps-sonys-hawk-eye-for-data-tracking-beginning-with-2023-24-season); [SportBusiness](https://tech.sportbusiness.com/news/nba-turns-to-hawk-eye-for-tracking-technology/))
- Second Spectrum kept a role (League Pass alternate broadcasts, 2D markings files for teams); the NBA disputed a Guardian characterization that its role was reduced. ([Sportico](https://www.sportico.com/business/tech/2023/nba-player-tracking-second-spectrum-dragon-1234711887/); [Guardian via PressReader](https://www.pressreader.com/usa/the-guardian-usa/20231021/282522958143935))

#### Per-game values from one-date dashboard queries
- `nba_stats_tracking.generate_tracking_game_logs(stat_measure, entity_type, date_from, date_to)` loops day by day (`rrule(DAILY, ...)`), calls `https://stats.nba.com/stats/leaguedashptstats` with `PerMode=PerGame`, `DateFrom` and `DateTo` both set to the day in `%m/%d/%Y`, skips days with no games, attaches `game_id` and `opponent_team_id` from helper maps, and re-maps each player's team because the API returns only the player's last team. `get_tracking_stats` sleeps 2 seconds before each request. ([nba_stats_tracking source](https://github.com/dblackrun/nba-stats-tracking/blob/master/nba_stats_tracking/tracking.py))
- The same package supports measures Drives, Defense, CatchShoot, Passing, Possessions, PullUpShot, Rebounding, Efficiency, SpeedDistance, ElbowTouch, PostTouch, PaintTouch, and an `aggregate_full_season_tracking_stats_for_seasons` helper. ([nba_stats_tracking docs](https://nba-stats-tracking.readthedocs.io/en/stable/source/modules.html))
- hoopR `nba_tracking_aggregate` sums `leaguedashptstats` across seasons, recomputes FG/FT percentages, drops other `_PCT` columns as non-additive, and is "designed and validated for COUNT-based tracking measures". ([hoopR: nba_tracking_aggregate](https://rdrr.io/cran/hoopR/man/nba_tracking_aggregate.html))

#### Current NBA.com definitions
- Rebound chance: "A player has a rebound chance if they are the closest player to the ball at any point in time" (a search snippet of the same page adds "between when the ball has crossed below the rim to when it is fully rebounded"). Contested REB: "an opponent is within 3.5 feet of the rebounder". Deferred REB Chances: "has a rebound chance, but defers the rebound to a teammate". Adjusted Rebound Chance %: rebounds per chance excluding deferred. Box outs: "physical contact with an opponent who was actively pursuing a rebound". ([NBA.com Stat Glossary](https://www.nba.com/stats/help/glossary))
- Potential Assists: "Any pass to a teammate who shoots within 1 dribble of receiving the ball". Secondary Assist: pass to a player who recorded an assist "within 1 second". Free Throw Assists: pass to a player who drew a shooting foul. Assist Points Created, Passes Made, Passes Received, Touches, Front Court Touches, Time of Possession (minutes), Elbow Touches (receives near the free throw line), Post Touches, Paint Touches (receives inside the lane), Drives ("attacks the basket off the dribble in the halfcourt offense"), Distance, Avg Speed, Contested Shots, Deflections, Loose Balls Recovered, Screen Assists. ([NBA.com Stat Glossary](https://www.nba.com/stats/help/glossary))
- The G League glossary lists Deferred DREB/OREB/REB Chances and Adjusted DREB/OREB/REB Chance %, so offensive and defensive splits exist for both. ([G League glossary](https://stats.gleague.nba.com/help/glossary))

## Q2. Is there evidence that rebound chances, contested rebound percentage, box outs, potential assists, or touches add predictive power for next-game rebounds or assists after controlling for minutes and past per-minute rates?

### Takeaway
I found no published study, academic or practitioner, that measures the incremental out-of-sample lift of rebound chances, contested rebound %, box outs, potential assists or touches for next-game rebounds or assists after controlling for minutes and past per-minute rates. The measured evidence is indirect: box-score rebound and assist rates already correlate about 0.91 to 0.95 season to season; tracking-based rebounding impact models are much more stable year to year (R-squared 0.60 to 0.77) than single-season adjusted rebounding impact (0.10 to 0.16); teammates overlap heavily on rebound chances; and home scorekeepers shifted team assist totals by up to about 5.8 per game between arenas in 2015-16. Claims that rebound chances or potential assists beat raw averages for props are asserted, not tested.

### Cited Findings

#### Baseline stability of box-score rates
- [MEASURED] Neil Paine, Basketball-Reference blog (2011-07-09): 1,866 player-seasons (500+ minutes in consecutive seasons, ages 24 to 34, players who moved into a new role). Correlation of a player's prior-season rate with his current rate vs. with the role's prior occupant: OReb% 0.933 vs 0.648; DReb% 0.918 vs 0.674; TReb% 0.950 vs 0.718; Ast% 0.906 vs 0.681. He writes that "a great deal of Assist% is role-dependent" and the rebound rates are similar. ([Basketball-Reference blog](https://www.basketball-reference.com/blog/index1540.html?p=9776))
- [MEASURED, values only in a figure] Franks, D'Amour, Cervone, Bornn (2016), 70 NBA metrics from 2000 onward: rebounds, blocks and assists "are highly discriminative and stable"; per-minute or per-game metrics are more stable but less discriminative than totals, because injuries move totals. Box score data only, no tracking. ([arXiv 1609.09830](https://arxiv.org/pdf/1609.09830))
- [MEASURED] Phil Birnbaum (2010-11 data): a player's defensive rebound percentage takes away about 0.8 from teammates on average ("stealing"), with high standard errors. ([Sabermetric Research](http://blog.philbirnbaum.com/2011/01/2010-11-nba-rebounding-correlations.html))

#### Rebounding tracking evidence
- [MEASURED] A Jump Shot in the Dark (2023-07-03): about 180 players with 4,000+ minutes over 2020-21 to 2022-23, NBA stats API via hoopR, per 36 minutes. Year-over-year R-squared, 2021-22 to 2022-23, min 500 minutes: single-season ridge-regressed offensive rebounding rate 0.16, defensive 0.10; tracking-built oERI 0.77; dERI linear 0.60; dERI XGBoost 0.64. Players with 150 to 1,000 minutes in both seasons (n=52): oERI 0.58, dERI XGBoost 0.50, dERI linear 0.40. Fitted oERI = 0.89 x contested OREB/36 + 2.18 x uncontested OREB/36 - 0.13 x height + 7.74; offensive box outs were not significant. For defense, box outs and contested rebounds per 36 ranked first in XGBoost importance, adjusted D-reb chance % had a small positive effect, average D-reb distance a moderate negative effect; XGBoost test RMSE 0.81 vs a target SD of 0.97 on a random 20% holdout. The target is a three-year ridge-regressed team rebounding impact, not a player's box score rebounds, and there is no next-game test. ([A Jump Shot in the Dark](https://jumpshotinthedark.com/2023/07/03/quantifying-the-nbas-most-impactful-rebounders-using-tracking-data/))
- [MEASURED] Seth Partnow, Nylon Calculus (2016-01-13, SportVU): about 59.5% of missed field goals end in uncontested defensive rebounds; uncontested defensive rebounds are worth about half of other rebounds (regression); adjusted rebound totals came to about 71% of actual rebounds league-wide. ([FanSided/Nylon Calculus](https://fansided.com/2016/01/13/deep-dives-random-rebound-observations))
- [MEASURED] Seth Partnow (2016-04-05, 2014-15 SportVU, "chasing" = within 3.5 ft when the rebound is secured): a 3.1% rise in lineup offensive chase aggression is worth 1 point of OREB%; about one in three offensive contests is a double-up on a teammate's contested board; defensive contests run about 7:1 (five double-ups, one loss, one marginal win per seven contests); the uncontested share of defensive rebounds rose from around 57% to around 60% across three SportVU seasons. ([FanSided/Nylon Calculus](https://fansided.com/2016/04/05/deep-dives-investigating-rebound-tradeoffs))
- [MEASURED, descriptive] Maheswaran, Chang et al., Sloan 2014 "The Three Dimensions of Rebounding": positioning (value of the court area a player controls at the shot), hustle (share of misses where a player becomes closest to the ball), conversion (rebounds divided by opportunities). The listing reports no predictive or stability numbers. ([Sloan](https://sloansportsconference.com/research-papers/the-three-dimensions-of-rebounding); earlier work: [Sloan 2012](https://www.sloansportsconference.com/research-papers/deconstructing-the-rebound-with-optical-tracking-data))
- [ASSERTED] Bleacher Report "Rebounder Rating" combines rebound chances, contested and uncontested rebounds to credit contested wins; no predictive test reported. ([Bleacher Report](https://bleacherreport.com/articles/2195424-how-brs-new-rebounder-rating-proves-not-all-nba-boards-are-created-equal))
- [ASSERTED] Rebound chances are called a "superior indicator" to rebounds per game because pace inflates raw totals; no backtest. ([The Wager Theorem](https://thewagertheorem.com/nba-prop-bet-stats-better-than-points/))
- [ASSERTED] Box-out leaders can signal future rebounding and help after team changes; a teammate often gets credit for a rebound another player created with a box out. ([RotoBaller](https://www.rotoballer.com/hustle-beats-talent-when-talent-doesnt-hustle/457544))
- [ASSERTED] "True Rebounding Rate" weights contested rebounds 1.25 and uncontested 0.9 and subtracts deferred chances to match NBA.com's adjusted DREB chance %; no validation numbers. ([The Zone Master](https://thezonemaster.substack.com/p/true-rebounding-rate))

#### Assist tracking evidence
- [MEASURED] van Bommel and Bornn, "Adjusting for Scorekeeper Bias in NBA Box Scores" (Data Mining and Knowledge Discovery, 2017): SportVU data for 1,227 of 1,230 2015-16 regular-season games (the arXiv abstract page says 2014-15; the PDF body says 2015-16). They define a potential assist as a completed in-play pass to a shooter who scores within seven seconds with no intervening rebound, turnover or pass (made shots only, unlike NBA.com's one-dribble rule). Of 82,493 such passes, 54,111 (65.59%) were recorded as assists. Mean home-team "scorekeeper bonus" ranged from -3.44 assists per game (Utah) to +2.32 (New Orleans) against a 22.05 team average, a 5.76 assist spread; scorekeeper variance ranged from 1.09 home and 1.21 away (Clippers) to 4.03 home and 4.54 away (New Orleans). ([arXiv 1602.08754](https://arxiv.org/pdf/1602.08754))
- [MEASURED, weak] Devin Jordan (2013-11-19), top 100 players in assist opportunities per game, 2013-14 through Nov 19: correlation .42 between conversion rate (cAST%) and assists; xAST = 11.405 x cAST% - 1.2663; regressed AST = (xAST - AST) x 0.17639 + AST; no out-of-sample test. ([davidgonos.com](https://davidgonos.com/?p=7894))
- [MEASURED, classifier only] Squared2020 (2019-01-25): an SVM reproduced assist crediting on made field goals with 98.77% recall (leave-one-out); most assists occur within the first 1.5 seconds after the catch, usually on zero or one dribble. Not a forecast of future assists. ([Squared Statistics](https://squared2020.com/2019/01/25/the-potential-assist/))
- [ASSERTED] Players with high assist-to-potential-assist ratios would probably see assists decline after a trade. ([RotoWire](https://web7.rotowire.com/basketball/article/impact-of-a-trade-43901))
- [ASSERTED] If teammates' shooting on a player's potential-assist passes runs below average, his assists should rise (regression to the mean). ([APBRmetrics forum](https://apbr.org/metrics/viewtopic.php?t=201&start=15))
- [NO NUMBERS] A GitHub study of the top 50 assist players plotted assists against potential assists and AST-to-pass % and found the relation "mostly linear"; no statistics. ([vivekdivakarla12/NBA-Potential-Assists](https://github.com/vivekdivakarla12/NBA-Potential-Assists))

#### Prop-model projects (no tracking features)
- [MEASURED] A public prop model using rolling per-minute production, a minutes model, opponent context, pace-normalized usage, rest and home/away reports +0.4% lift over a naive last-5-games baseline for rebounds in 2025-26 and inconsistent assist lift across seasons. ([tredaman5/NBA-Player-Prop-Model](https://github.com/tredaman5/NBA-Player-Prop-Model))
- [MEASURED] A University of Michigan student rebound model beat a baseline of average rebounds plus height by about 2% lower test error; no tracking features. ([micrubin1/nba-rebound-prediction-model](https://github.com/micrubin1/nba-rebound-prediction-model))

#### Touches
- No study linking touches, front court touches or time of possession to future rebounds or assists was found in searches covering Nylon Calculus, Squared2020, arXiv and betting sites. ([example search hit with no such test: GiveMeSport](https://www.givemesport.com/playmaking-goes-far-beyond-assists-in-modern-nba/))

### Inferences
- Both targets decompose into opportunity times conversion: REB = REB_CHANCES x REB_CHANCE_PCT and AST = POTENTIAL_AST x (AST / POTENTIAL_AST). The cited work shows conversion depends on teammates (Partnow's double-ups, Birnbaum's 0.8 stealing) and, for assists, on teammate shooting and the home scorekeeper (van Bommel and Bornn). Projecting opportunity per minute with light shrinkage and conversion with heavy shrinkage toward player and position priors is a reasonable hypothesis to test; no source measures its lift.
- Season-level box-score rates already correlate at 0.91 to 0.95, so tracking features have little room to add at the season level. If they add anything for next-game props, it is most likely early in the season, after role changes (trades, teammate injuries, lineup changes), and when conversion has run hot or cold over a short window. This is a hypothesis.
- Assist props: include a home-arena (scorekeeper) effect. A 5.76 team-assist spread between the extreme arenas in 2015-16 is large relative to individual assist lines, though its size today is unknown.
- Box outs: the one quantitative source found offensive box outs not significant and defensive box outs important for team defensive rebounding impact, not for a player's own rebound count. Box outs may lower a player's own rebounds when teammates collect the ball (`BOX_OUT_PLAYER_TEAM_REBS` vs `BOX_OUT_PLAYER_REBS`), so the sign for individual rebound props should be checked empirically.
- Test design the user can run: baseline = projected minutes x exponentially weighted per-minute REB or AST plus opponent and pace terms; add per-minute REB_CHANCES (O and D), contested share, deferred share, adjusted chance %, box outs, POTENTIAL_AST, PASSES_MADE, TOUCHES, TIME_OF_POSS, all computed only from prior games; rolling-origin evaluation by week; score with log loss or Brier on P(over) at the posted line, plus MAE on counts; run 2017-18 to 2022-23 (one provider) separately from 2023-24 onward.

### Gaps
- No measured next-game or next-season lift for any of the named tracking stats over minutes plus per-minute baselines.
- No split-half reliability or stabilization point (games needed) was found for rebound chances, contested %, adjusted chance %, box outs, potential assists, passes or touches.
- Not read: the full Sloan 2014 rebounding paper (not posted on the listing page), the Sloan "Rebound Rate Over Expected" paper ([Sloan listing](https://www.sloansportsconference.com/research-papers/enhancing-nba-true-shot-charts-a-probabilistic-spatial-approach-to-rebounding-and-possession-value)), and FTN's "Not All Assists Are Created Equal" (HTTP 403).
- No Cleaning the Glass, FiveThirtyEight or Basketball Index study with tracking-based reliability numbers for rebounds or assists surfaced in searches.

## Q3. What practical throughput can a free user get from stats.nba.com (requests per minute, recommended sleep, typical failure modes), and which endpoints are known to be slow or unreliable?

### Takeaway
There is no published rate limit. Practitioner code paces at about 2 seconds per request, and the common failures are silent hangs until the 30-second read timeout, blocking of datacenter and CI IPs, broken requests after header or User-Agent changes, empty result sets from parameter-format errors, and HTTP 500 or empty JSON from retired V2 endpoints. A residential Windows machine with current nba_api headers is the supported case; at 2 to 3 seconds per call that is roughly 1,200 to 1,800 calls per hour (inference).

### Cited Findings
- nba_api's stats client sends to `https://stats.nba.com/stats/{endpoint}` with default headers: `Host: stats.nba.com`, a Chrome 145 macOS `User-Agent`, `Accept: application/json, text/plain, */*`, `Accept-Language: en-US,en;q=0.5`, `Accept-Encoding: gzip, deflate, br`, `Connection: keep-alive`, `Referer: https://www.nba.com/`, `Pragma: no-cache`, `Cache-Control: no-cache`, `Sec-Ch-Ua`, `Sec-Ch-Ua-Mobile: ?0`, `Sec-Fetch-Dest: empty`; no `Origin`; no retry or rate-limit logic in that file; a generic `{"Message":"An error has occurred."}` body is rewritten to an error string. ([nba_api http.py](https://github.com/swar/nba_api/blob/master/src/nba_api/stats/library/http.py))
- nba_api header history: v1.10.2 (2025-09-30) "Updated HTTP headers to resolve connection timeouts" and dropped `x-nba-stats-origin` and `x-nba-stats-token`; v1.11.4 (2026-02-20) fixed requests broken by "an outdated user agent"; v1.11.6 (2026-10-22) "cdn.nba.com had started rejecting the default request headers with 403 Access Denied"; v1.12.0 (2026-10-24) stopped a request's `Referer` leaking into shared default headers and added `NBA_API_REQUIRE_PROXY=1`. ([nba_api CHANGELOG](https://github.com/swar/nba_api/blob/master/CHANGELOG.MD))
- Endpoint failures in the same changelog: BoxScorePlayerTrackV2 HTTP 500 (removed 2025-11-13); V2 Advanced, FourFactors, Misc, Scoring and Usage box scores "No Longer Served" (2026-10-24); BoxScoreTraditionalV2 deprecated (2025-11-11); PlayByPlayV2 "returns empty JSON"; ScoreboardV2 "returns empty line scores for 2025-26 season games" (2026-02-20); TeamGameLog and TeamGameLogs "Deprecated by the NBA with no replacement available" (2025-11-11); PlayerGameLogs with a blank `Season` returns HTTP 500 (fixed 2026-10-24). ([nba_api CHANGELOG](https://github.com/swar/nba_api/blob/master/CHANGELOG.MD))
- Read timeouts: nba_api issue #176 (opened Nov 2020, closed Feb 2021) carries `HTTPSConnectionPool(host='stats.nba.com')` read timeouts at 30 seconds, with reports that code failing on hosted servers worked locally. ([nba_api #176 mirror](https://github.lx164.workers.dev/swar/nba_api/issues/176))
- Cloud and CI blocking: a Stack Overflow question reports nba_api timeouts only inside a GitHub Actions workflow; another reports the NBA blacklisting cloud hosts such as AWS, DigitalOcean and Heroku. ([Stack Overflow mirror: GitHub workflow](https://kiwix.lema.org/stackoverflow.com_en_all_2023-11/questions/73066785/nba-api-timeouts-when-run-with-github-workflow); [Stack Overflow mirror: production](https://kiwix.lema.org/stackoverflow.com_en_all_2023-11/questions/63892430/remote-api-call-working-local-but-not-working-in-production))
- A Hacker News comment (about eight months before October 2026) states that stats.nba.com "sits behind Akamai bot protection that rejects requests based on TLS fingerprints" and "silently drops connections from datacenter IPs. AWS, GCP, Azure, all blocked", and that cdn.nba.com live endpoints had "no protection" (the last point is contradicted by nba_api's 2026-10-22 note on cdn.nba.com 403s). Single unverified comment. ([Hacker News](https://news.ycombinator.com/threads?id=gek0z))
- Pacing used in practice: `nba_stats_tracking` calls `time.sleep(2)` before every request, with a code comment that requesting too quickly causes timeouts. ([nba_stats_tracking source](https://github.com/dblackrun/nba-stats-tracking/blob/master/nba_stats_tracking/tracking.py)); an nba_py tutorial adds a sleep between pulls. ([Medium: Hardwood Convergence](https://medium.com/hardwood-convergence/showtime-pulling-multiple-seasons-of-player-stats-with-nba-py-6b00138c5238))
- Empty results: LeagueDashPtStats zero rows (issue #688, August 2026, season-format suggestion); TeamDashPtPass empty DataFrame (issue #177, closed January 2021). ([nba_api #688](https://github.com/swar/nba_api/issues/688); [nba_api issues search](https://github.com/swar/nba_api/issues?q=is%3Aissue%20hustle%20OR%20playertrack%20OR%20leaguedashptstats))
- A Python client describes stats.nba.com as "notorious for being extremely unreliable" [ASSERTED]. ([nbapy on PyPI](https://pypi.org/project/nbapy/1.1.7/))

#### Free wrappers and mirrors
- nba_api (Python, swar): latest v1.12.0 dated 2026-10-24. ([nba_api CHANGELOG](https://github.com/swar/nba_api/blob/master/CHANGELOG.MD))
- hoopR (R, sportsdataverse): `nba_leaguedashptstats`, `nba_boxscoreplayertrackv3`, `nba_hustlestatsboxscore`, `nba_playerdashptreb`, `nba_tracking_aggregate`. ([hoopR refman](https://search.r-project.org/CRAN/refmans/hoopR/html/nba_leaguedashptstats.html); [hoopR playerdashptreb](https://search.r-project.org/CRAN/refmans/hoopR/html/nba_playerdashptreb.html))
- nba_stats_tracking (Python, dblackrun): tracking game logs by date range. ([docs](https://nba-stats-tracking.readthedocs.io/en/stable/source/modules.html))
- nbastatR (R, abresler): wraps NBA Stats, Basketball-Reference and others; an aggregator shows a last push on 2026-03-07 and 107 open issues; no evidence on whether its tracking calls still work. ([gittrend](https://gittrend.io/repo/abresler/nbastatR); [GitHub](https://www.github.com/abresler/nbastatR))
- pbpstats: a play-by-play parsing package plus a free API documented at api.pbpstats.com/docs; no tracking endpoints found. ([pbpstats docs](https://pbpstats.readthedocs.io/); [FastBreakR article](https://jessekartes.github.io/FastBreakR/articles/pbpstats.html))
- balldontlie: games, teams, players, box scores, season averages; free tier listed at 5 requests per minute with an API key; no tracking or hustle categories found. ([freeapihub listing](https://freeapihub.com/apis/balldontlie-api))

### Inferences
- Throughput: at a 2-second sleep plus 0.5 to 2 seconds of response time, expect about 20 to 30 calls per minute, or 1,200 to 1,800 per hour, from one residential IP. Run calls serially; parallel threads raise the chance of the silent-drop pattern.
- Call budget per regular season (about 1,230 games on roughly 160 to 170 game dates): the GameID approach (V3 track plus hustle V2) is about 2,460 calls; the one-date dashboard approach (Rebounding, Passing, Possessions, Drives, SpeedDistance plus one hustle call) is about 1,000 calls and also returns potential assists, contested and deferred rebounds, and time of possession. Per-player endpoints (`playerdashptreb`, `playerdashptpass`) need one call per player per window (450 to 550 players a season), so they are slow by volume.
- Residential Windows specifics: a home IP avoids the datacenter blocking reported above, but a VPN that exits through a datacenter would not. Use one `requests.Session`, explicit timeouts (connect about 10 s, read 30 to 60 s), retries with exponential backoff and jitter on timeouts and 5xx, and a retry queue keyed by date or GameID. Cache every raw JSON response to disk so a backfill never repeats a call. Keep the machine awake for overnight backfills (power settings or Task Scheduler). If copying nba_api's headers into plain `requests` code, the `br` in `Accept-Encoding` needs the `brotli` package installed for decoding, or drop `br` (unverified; check that the response body decodes as JSON). Pin nba_api and upgrade when requests start failing: the changelog shows header fixes in September 2025, February 2026 and October 2026.
- Pass `Season` in `YYYY-YY` form matching the date, and dates as `MM/DD/YYYY` (the format used by `nba_stats_tracking`).

### Gaps
- No official or measured request-per-minute limit, no measured per-endpoint latency, and no published list of games missing tracking data (the NBA.com glossary links a "Video & Tracking Status" page that could not be read).

## Q4. How do tracking definitions differ between the Second Spectrum and the Sportradar or Hawk-Eye eras, and are there known discontinuities in rebound chances, drives, or touches around 2023-24 that would break a multi-season model?

### Takeaway
The hardware and vendor changed twice (SportVU to Second Spectrum in 2017-18, Second Spectrum to Hawk-Eye with Sportradar in 2023-24), the published rebound chance definition changed wording from a 3.5-foot vicinity rule (SportVU era) to a closest-player rule (current glossary), and box out measurement reportedly changed after 2018-19. I found no published audit of level shifts in rebound chances, drives or touches at 2023-24, so 2017-18, 2019-20 and 2023-24 should be treated as candidate breakpoints and tested before pooling seasons.

### Cited Findings
- SportVU-era wording (2015) attributed to NBA.com: rebound chances = "number of times player was within the vicinity (3.5 ft) of a rebound". ([Space City Scoop](https://spacecityscoop.com/2015/08/28/nba-player-stats-top-5-players-rebounding))
- SportVU-era analysts defined a chase as being within 3.5 feet of the ball when the rebound is secured. ([Nylon Calculus, 2016](https://fansided.com/2016/04/05/deep-dives-investigating-rebound-tradeoffs))
- Current NBA.com wording: a rebound chance goes to a player who is "the closest player to the ball at any point in time" between the ball crossing below the rim and the rebound; contested still means an opponent within 3.5 feet. ([NBA.com Stat Glossary](https://www.nba.com/stats/help/glossary))
- Box out methodology "dramatically changed" after 2018-19, which stopped one analyst from using a five-season sample. ([A Jump Shot in the Dark](https://jumpshotinthedark.com/2023/07/03/quantifying-the-nbas-most-impactful-rebounders-using-tracking-data/))
- Hardware: Second Spectrum's older system used six rafter cameras tracking torsos in 2D (a single point per player); Hawk-Eye pose tracking uses 14 cameras tracking 29 body points per player plus the ball in 3D. ([Sportico](https://www.sportico.com/business/tech/2023/nba-player-tracking-second-spectrum-dragon-1234711887/); [SVG](https://www.sportsvideo.org/2023/03/09/nba-taps-sonys-hawk-eye-for-data-tracking-beginning-with-2023-24-season)); the earlier camera systems updated at 25 frames per second. ([Wikipedia](https://en.wikipedia.org/wiki/Player_tracking_(National_Basketball_Association)))
- A 2023 University of South Carolina senior thesis argues that failing to account for tracking-system changes may leave an exploitable gap when comparing data across the transition (seen in a search snippet; full text returned HTTP 403). ([Scholar Commons](https://scholarcommons.sc.edu/cgi/viewcontent.cgi?article=1747&context=senior_theses))
- Searches for documented 2023-24 changes to NBA.com rebound chances, touches, drives or potential assists returned no methodology notes or audits; the Wikipedia history page does not cover Hawk-Eye. ([Wikipedia](https://en.wikipedia.org/wiki/Player_tracking_(National_Basketball_Association)))

### Inferences
- The rebound chance wording change could reflect a real definitional change at 2017-18 (vendor switch) or later; the timing is undocumented. A closest-player rule and a within-3.5-feet rule would produce different counts, especially for players near crowded rebounds.
- The prop targets (box score rebounds and assists) do not change with tracking vendors, so only tracking features drift. Practical fixes: era indicators, standardizing tracking features within season (z-scores or share of team totals), or training on 2023-24 onward for features that show a level shift.
- Detection test (about 65 calls): pull `leaguedashptstats` with `PlayerOrTeam=Team`, `PerMode=PerGame` for each season 2013-14 to 2025-26 and each of Rebounding, Passing, Possessions, Drives, SpeedDistance, plus `leaguehustlestatsplayer` totals. Plot league means per team-game of REB_CHANCES, contested and deferred shares, POTENTIAL_AST, PASSES_MADE, TOUCHES, TIME_OF_POSS, DRIVES and BOX_OUTS; also compare REB / REB_CHANCES and AST / POTENTIAL_AST for players who played both 2022-23 and 2023-24. Team rebounds and assists per game move slowly, so a jump in chances per team rebound or potential assists per team assist across a vendor change would indicate a measurement shift.

### Gaps
- No primary NBA document dates the rebound chance wording change.
- No published comparison of Second Spectrum vs Hawk-Eye values for drives, touches, passes, potential assists or rebound chances.
- No Hawk-Eye-era methodology notes from the NBA, Sportradar or Sony for NBA.com tracking stats were found.

## Q5. Are there free or cheap historical dumps of per-game tracking box scores so a backtest does not need thousands of live API calls, and what tracking data is not free?

### Takeaway
I found no free dump of per-game tracking or hustle box scores for 2017-18 to 2025-26; the practical route is a self-built cache using one-date dashboard calls (about 1,000 calls per season). Free raw coordinates exist only for part of 2015-16 (SportVU, about 600 to 631 games). Second Spectrum and Hawk-Eye raw coordinates and pose data and Synergy video are commercial; NBA.com exposes only aggregated tracking and season-level play type summaries.

### Cited Findings
- Kaggle box score datasets found (all player box scores 1946 to April 2023 scraped with nba_api; 2024-25 box scores) list no tracking or hustle fields in their descriptions. ([Kaggle via Baselight: loganlauton](https://baselight.app/u/kaggle/dataset/loganlauton_nba_player_box_score_data); [Kaggle via Baselight: albi9702](https://baselight.app/u/kaggle/dataset/albi9702_nba_boscoscore_2024_25))
- `shufinskiy/nba_data`: play-by-play from stats.nba.com (1996-97 on), pbpstats (2000-01 on), data.nba.com (2016-17 on, with action coordinates), shot details, matchups (2017-18 to 2024-25), as `.tar.xz` CSVs with R and Python loaders, a Kaggle copy and a Google Drive archive; last listed update 2025-02-26; no tracking or hustle box scores. ([GitHub](https://github.com/shufinskiy/nba_data))
- `gabriel1200/site_Data`: public repo (1,282 commits) with `tracking`, `player_tracking`, `hustle.csv`, `playtype` folders and season folders 2014 to 2027; granularity (per game vs per season) not documented; its hosted docs now return HTTP 410. ([GitHub](https://github.com/gabriel1200/site_Data))
- Raw SportVU 2015-16: hosted in `neilmj/BasketballData` (folder `2016.NBA.Raw.SportVU.Game.Logs`, one 7z-compressed JSON per game; listing shows last update 2019), mirrored by `sealneaward/nba-movement-data` and repackaged on Hugging Face from `linouk23/NBA-Player-Movements` merged with play-by-play. ### Inferences
- Build-your-own cache: about 165 dates x 6 calls = about 1,000 calls per regular season, roughly 50 to 80 minutes per season at 3 to 5 seconds per call; 2017-18 through 2025-26 (nine seasons) is about 9,000 calls, one or two overnight runs on the residential machine. Add V3 track and hustle V2 GameID calls (about 2,460 per season) only for fields that exist only there.
- Keep play-by-play based features (minutes, lineups, on-court teammates) from `shufinskiy/nba_data` or pbpstats to avoid re-pulling them from stats.nba.com.
- The 2015-16 SportVU files would let a user derive custom rebound and pass opportunity metrics, but they cover one partial season of a retired system and do not match current NBA.com definitions, so they have little direct value for a 2026-27 model.

### Gaps
- Kaggle, Hugging Face and Zenodo were searched only through a web search engine; a per-game tracking dump could exist without being indexed.
- Live availability of the `neilmj/BasketballData` repo was not confirmed.
- No pricing was found for Second Spectrum, Hawk-Eye or Synergy data access.
